Configurar Supabase (Sincronización Cloud)

Supabase es una base de datos gratuita. Con esto puedes acceder a tus datos desde cualquier dispositivo: PC, celular, tablet. Solo configúralo una vez.

Paso 1: Ve a supabase.com → crea cuenta gratis → crea proyecto.

Paso 2: En SQL Editor ejecuta:

create table airdrops ( id text primary key, name text not null, type text, ecosystem text, explorer text, status text default 'activo', points numeric default 0, tokens numeric default 0, premarket numeric default 0, sold_tokens numeric default 0, sold_usd numeric default 0, invested numeric default 0, potential numeric default 0, profit numeric default 0, date_start text, date_end text, notes text, created_at timestamptz default now(), updated_at timestamptz default now() ); create table claims ( id text primary key, airdrop_id text, airdrop_name text, date text, tokens_claimed numeric default 0, tokens_sold numeric default 0, usd_sold numeric default 0, fee numeric default 0, net numeric default 0, notes text, created_at timestamptz default now() ); alter table airdrops enable row level security; alter table claims enable row level security; create policy "allow all" on airdrops for all using (true) with check (true); create policy "allow all" on claims for all using (true) with check (true);

Paso 3: Settings → API → copia URL y anon key:

Migrar datos locales → Supabase
